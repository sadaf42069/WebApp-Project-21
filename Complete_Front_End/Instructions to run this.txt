1. Install Node.js 22 or newer.
2. Open this folder in VS Code.
3. Open the integrated terminal.
4. Optional: copy .env.example to .env and replace deployment secrets.
5. Run: npm.cmd install
6. Run the automated checks: npm.cmd test
7. Run the production build check: npm.cmd run build
8. Start development: npm.cmd run dev
9. Open: http://localhost:8443
